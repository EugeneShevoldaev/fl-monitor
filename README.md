# FL.ru → Telegram: монитор заказов по RSS

Бот-монитор: читает **официальную RSS-ленту** [FL.ru](https://www.fl.ru/projects/)
и публичную ленту [freelance.ru](https://freelance.ru/task), считает вес каждого
заказа по словарю и присылает в Telegram только то, что похоже на вашу
специализацию. Парсинга сайтов нет — только открытые ленты, поэтому капчу и бан
не ловим.

## Зачем

Заказы на биржах разбирают быстро: на простые задачи приходит 60–100 откликов
за первые двое суток. Ручной просмотр ленты не успевает — пока читаешь,
заказ уже отдан.

Скрипт делает фильтр за вас: приходит только релевантное, остальное отсекается
до того, как вы его увидите.

## Результат

За две недели работы (28.10–11.11.2026):

| Показатель | Значение |
|---|---|
| новых заказов в ленте | **1703** |
| прошло фильтр | **133** |
| доля отсева | **92,2 %** |
| прогонов по cron | 615 (каждые 5 минут) |

## Как работает

```
RSS fl.ru / freelance.ru  →  подсчёт веса  →  Telegram
```

1. Забирает ленты: `https://www.fl.ru/rss/all.xml` и `https://freelance.ru/task`.
2. Считает вес заказа: каждое слово из словаря добавляет или отнимает баллы.
3. Применяет поправку на умения: что делаем — плюс, что рискованно — минус.
4. Отсекает то, чего не делаем вовсе, и заказы «под ключ» на месяц вперёд.
5. Если вес ≥ порога — отправляет сообщение в Telegram.
6. Помнит уже виденные заказы в `state.json`, чтобы не дублировать.

## Фильтры

| Блок | Что делает |
|---|---|
| `KEYWORDS` | словарь «слово → вес»; отрицательный вес отсекает (античит, накрутка, 1С, Bitrix) |
| `ABILITY_OK` | признаки нашей темы: Excel, парсинг, скрипты, боты, nginx, VPS, документы |
| `ABILITY_RISKY` | можем, но рискованно: Vue/React, админки, мобильные, CRM/ERP — минус к весу |
| `ROLE_NO` | не наше по роли: «сеньор», «архитектор», «тимлид», «% от» |
| `ABILITY_NO` | не наше вовсе: 1С, Bitrix, Flutter, iOS, 3D, госзакупки, приманки |
| `MONTH_SCALE` | заказ на месяц: если набралось 3+ признака (система, интеграция, аналитика, роли, мобильность, QR/камера, «под ключ») — не показываем |
| бюджет | дешёвые (< 1 000 ₽) не берём; ≥ 50 000 ₽ помечаем «крупный — не для старта» |
| `TAG_BLOCK` | «недорого» — отдельная строка, не больше одной за проход: такие заказы берут ради отзыва |
| конкуренция | считает отклики в сутки: < 12 низкая, 12–40 средняя, > 40 высокая |

Правила меняются по живому опыту и записаны в `FILTERS.md` (в рабочей копии)
с датой и причиной каждого.

## Установка

Нужен только Python 3.9+ и стандартная библиотека — сторонних пакетов нет,
`pip install` не требуется.

```bash
git clone <этот-репозиторий>
cd fl-monitor
cp config.example.json config.json
chmod 600 config.json
```

В `config.json` впишите:

```json
{
  "token": "ТОКЕН_БОТА_ОТ_BOTFATHER",
  "chat_id": 0
}
```

- **Токен** — у [@BotFather](https://t.me/BotFather): `/newbot`, затем скопировать токен.
- **chat_id** — напишите своему боту `/start`, затем откройте
  `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите `result[0].message.chat.id`.

Первый запуск:

```bash
python3 fl-monitor.py
```

Все файлы состояния ищутся рядом со скриптом, поэтому каталог можно положить куда угодно.

## Запуск по расписанию

```cron
*/5 * * * * cd /path/to/fl-monitor && /usr/bin/python3 fl-monitor.py >> cron.log 2>&1
```

## Флаги

| Флаг | Что делает |
|---|---|
| `--dry-run` | пробный прогон: ничего не отправляет и не запоминает, только пишет в лог |
| `--recheck` | перепроверяет ленту новыми правилами и присылает то, что раньше отсеяли |

## Пример сообщения

```
🎯 Разработка парсера маркетплейса
💰 7 000 ₽
📄 ТЗ: 12 стр., 3 400 зн.
🏷 недорого
📂 Программирование / Python
⚖️ вес 9
https://www.fl.ru/projects/...
```

Крупные заказы приходят с пометкой `🏗 крупный — не для старта`,
дешёвые «на отзыв» — с пометкой `🏷 недорого — для отзыва`.

## Настройка под себя

Всё в начале `fl-monitor.py`:

| Что | Смысл |
|---|---|
| `KEYWORDS` | слова и веса; отрицательный вес отсекает заказы |
| `THRESHOLD` | минимальный вес для отправки (сейчас 6) |
| `MAX_PER_RUN` | максимум сообщений за проход (защита от спама) |
| `MAX_STATE` | сколько id заказов помнить |
| `BIG_BUDGET` | с какого бюджета помечать «крупный» |
| `SMALL_MIN` | нижняя граница бюджета |
| `MONTH_SCALE_MIN` | сколько признаков «большой системы» считать отсечкой |

Пример: чтобы искать только парсинг и ботов, поднимите `THRESHOLD` до 10
и оставьте в словаре десяток слов.

## Чего здесь нет

- Нет обхода капчи и авторизации — только открытые ленты.
- Нет автоотклика: решение принимает человек.
- Нет отправки в другие мессенджеры — только Telegram Bot API.
