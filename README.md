# FL.ru → Telegram: монитор заказов по RSS

Небольшой бот-монитор: читает **официальную RSS-ленту** [FL.ru](https://www.fl.ru/projects/)
и присылает в Telegram только те новые заказы, которые подходят под заданные
ключевые слова. Парсинга сайта нет — только публичный RSS, поэтому капчу и бан
не ловим.

## Зачем

Заказы на фриланс-биржах разбирают быстро (иногда 20+ откликов за несколько часов).
Ручной просмотр не успевает. Этот скрипт делает фильтр за вас: приходит только
то, что похоже на вашу специализацию.

## Как работает

```
FL.ru RSS  →  фильтр по ключевым словам с весами  →  Telegram
```

1. Забирает `https://www.fl.ru/rss/all.xml` (около 60 свежих заказов).
2. Считает вес заказа: каждое слово из словаря добавляет свой вес,
   «плохие» слова (античит, накрутка, 1С, логотипы…) вычитаются.
3. Если вес ≥ порога — отправляет сообщение в Telegram.
4. Помнит уже виденные заказы в `state.json`, чтобы не дублировать.

## Установка

Нужен только Python 3.9+ и стандартная библиотека — сторонних пакетов нет.

```bash
git clone <этот-репозиторий>
cd fl-monitor
cp config.example.json config.json
chmod 600 config.json
```

В `config.json` впишите:

```json
{
  "token": "ТОКЕН_БОТА_ОТ_BOTFATHER",
  "chat_id": 0
}
```

- **Токен** — у [@BotFather](https://t.me/BotFather): `/newbot`, затем скопировать токен.
- **chat_id** — напишите своему боту любое сообщение (обязательно `/start`),
  затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите
  `result[0].message.chat.id`.

Первый запуск:

```bash
python3 fl-monitor.py
```

## Запуск по расписанию

```cron
*/30 * * * * cd /path/to/fl-monitor && /usr/bin/python3 fl-monitor.py >> cron.log 2>&1
```

## Настройка под себя

Всё в начале `fl-monitor.py`:

| Что | Где | Смысл |
|---|---|---|
| `KEYWORDS` | словарь | слова и веса; отрицательный вес отсекает заказы |
| `THRESHOLD` | константа | минимальный вес для отправки (сейчас 3) |
| `MAX_PER_RUN` | константа | максимум сообщений за проход (защита от спама) |
| `MAX_STATE` | константа | сколько id заказов помнить |

Пример: чтобы искать только Python и парсинг, поставьте
`THRESHOLD = 6` и оставьте в словаре пару слов.

Пример сообщения, которое приходит в Telegram:

```
🎯 Разработка парсера маркетплейса
💰 7 000 ₽
📂 Программирование / Python
⚖️ вес 9
https://www.fl.ru/projects/...
```
